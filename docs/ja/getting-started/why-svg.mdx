console2svgは、ターミナルの出力をSVGとして保存します。
SVGは単に画像を表示するだけでなく、ターミナルのような文字中心の画面を、きれいに・扱いやすく共有するのに適した形式です。

## どのサイズでも鮮明

まずは以下2つの画像を見比べてください。

```bash title="Terminal"
$ fastfetch
```

### SVG
{/* c2s::  -w 120 -h 24 -- fastfetch */}

### PNG
{/* c2s::  -w 120 -h 24 -- fastfetch */}


前者の方が文字がくっきりしていることがわかります。
SVGはベクター形式なので、拡大・縮小しても文字や罫線がぼやけません。README、ブログ記事、スライド、印刷物など、表示する場所やサイズが変わっても同じ品質を保てます。

## 容量が小さい

上記2つのファイルの容量を比較すると、SVG版のほうが圧倒的に小さい(1/5程度)ことがわかります。

## ブラウザでそのまま表示できる

SVGは主要なブラウザが標準で対応しているオープンなWeb標準です。
特別なビューアや変換ツールを用意しなくても、生成したファイルをブラウザで開いたり、MarkdownやHTMLに埋め込んだりできます。

```markdown title="README.md"
![your terminal output](./output.svg)
```
