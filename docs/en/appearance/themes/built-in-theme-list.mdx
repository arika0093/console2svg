---
title: Built-in theme overview
description: Browse the built-in themes included with console2svg by type.
---

The built-in themes in console2svg are divided into the following types.

* [Palettes](./built-in-palettes.mdx): Themes that change only the terminal color scheme
* [Window frames](./built-in-window-themes.mdx): Themes that specify macOS-style or Windows-style frames
* [Full themes](./built-in-full-themes.mdx): Themes that change the color scheme and window frame together

Apply a theme by passing its ID to `-t` or `--theme`.
Use `-d` or `--window` when specifying only a window frame.

```bash
console2svg capture --theme nord -- console2svg
console2svg capture --window macos-pc -- console2svg
console2svg capture --theme cyberpunk-pc -- console2svg
```
