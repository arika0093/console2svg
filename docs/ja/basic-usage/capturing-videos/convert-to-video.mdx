キャプチャしたSVGアニメーションをGIFやMP4などの一般的な動画フォーマットへ直接変換して出力できます。

## 出力例

`-o` オプションで目的の拡張子を指定します。システムに `ffmpeg` がインストールされている場合、自動的にエンコード処理が実行されます。

### GIFアニメーション

```bash title="Terminal" "-o demo.gif"
console2svg capture -v -o demo.gif -- cmatrix -ab
```

## 仕組み

アニメーションSVGは、そのままでは各種動画フォーマットに変換できません。そのため、大まかに以下の手順を経て変換処理が行われます。

<Steps>

1. 生成されたアニメーションを [save-frames](./save-frames) により各フレームごとのSVGとして抽出します。

2. `svg`から直接変換可能な場合(`librsvg`が有効な場合)は単純に、SVGを全て結合して`ffmpeg`に渡すだけです。

3. `svg`から直接変換できない場合、一度`resvg`により[PNG画像へ変換](../capturing-images/convert-to-png.md)してから, `ffmpeg`に渡します。

</Steps>

これにより、様々な環境で動画フォーマットへの変換が可能になります。
