---
title: update
description: console2svgの更新を確認・実行するコマンド。
---

```bash title="Terminal"
console2svg update [--check] [--force] [--yes]
```

`--check`は確認のみ、`--force`はパッケージマネージャー管理下でも更新、`--yes`は確認プロンプトを省略します。

## オプション

### `--check`

利用可能な更新の確認だけを行い、インストールしません。

### `-f, --force`

パッケージマネージャーが管理しているインストールでも更新します。

### `-y, --yes`

確認プロンプトを省略します。
