## 拍摄静态图片
### 简单示例

<Steps>

1. 使用 `console2svg capture -- (any-command)` 执行任意命令。

   ```bash title="Terminal"
   console2svg capture -- console2svg
   ```

2. 这样就完成了。默认会生成到 `output.svg`。

3. 在浏览器中打开生成的 `output.svg`。你应该会看到类似下面的输出。

   ![`console2svg capture -- console2svg` 的输出](/assets/cmd.svg)


</Steps>


### 指定选项

`capture` 支持若干（其实很多）选项参数。
例如，让 `oh-my-logo` 按以下条件显示。

* `-o console2svg.svg`：将输出目标更改为 `console2svg.svg`。
* `-w 100`：固定窗口宽度（默认自动）。
* `-c`：在输出开头添加类似 `$ oh-my-logo ...` 的执行命令显示。
* `-d macos-pc`：使其看起来像 macOS 窗口，并在周围添加留白。
   * 只指定 `-d` 时，会按 `macos`（无留白）处理。
* `--background "#ff7e5f" "#feb47b"`：使用 sunset 风格的渐变背景。

```bash title="Terminal" "-d macos-pc" "--background"
console2svg capture -o console2svg.svg -w 100 -h 10 -c -d macos-pc \
            --background "#ff7e5f" "#feb47b" \
            -- oh-my-logo "console2svg" sunset --filled --letter-spacing 0
```

## 拍摄视频
### 简单示例

<Steps>

1. 给 `capture` 命令传入 `-v`，然后执行任意命令。

   ```bash title="Terminal" "-v"
   console2svg capture -c -d -v -- sl
   ```

   > [!NOTE]
   > 未指定 <code>-v</code> 时，会生成只绘制最终帧的静态 SVG。

2. 以上即完成。生成结果如下所示。

   ![console2svg capture -c -d -v -- sl](/assets/cmd-sl.svg)

</Steps>

### 指定选项

例如，让 `nyancat` 按以下条件显示。

* `-w 160 -h 32`：宽度 160，高度 32。
* `-c`：在输出开头添加类似 `$ nyancat` 的执行命令显示。
* `-d`：使其看起来像 macOS 窗口（无留白）。等同于 `-d macos`。
* `-v`：启用视频输出。
* `--timeout 5`：经过 5 秒后自动结束。
* `--sleep 0.5`：从最终帧回到循环开头前等待 0.5 秒。

```bash title="Terminal" "-v" "--timeout 5" "--sleep 0.5"
console2svg capture -w 160 -h 32 -c -d -v \
            --timeout 5 --sleep 0.5 -- nyancat -d 10
```

![console2svg capture -w 160 -h 32 -c -d -v --timeout 5 --sleep 0.5 -- nyancat -d 10](/assets/cmd-nyancat.svg)

详情请参阅[拍摄视频](/zh/basic-usage/capturing-videos/overview/)页面。
