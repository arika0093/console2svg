## Overview

Convert terminal output into images for READMEs, blog posts, assignments, and documentation.

> This image is, of course, generated by console2svg itself. Beautiful, isn't it?


## What can it do?

There are lots of features! You are sure to find something you like.

<CardGrid stagger>
  <Card title="Generate beautiful SVG images" icon="star">
    Render ANSI and Truecolor output as SVG.
    It delivers high resolution that is perfect for your documentation.

    [Learn more →](/en/basic-usage/capturing-images/overview/) <br/>
    [Why SVG? →](/en/getting-started/why-svg/)
  </Card>
  <Card title="Generate videos too" icon="rocket">
    Want to share `cmatrix` output? You can do it in one shot.

    [Learn more →](/en/basic-usage/capturing-videos/overview/)
  </Card>
  <Card title="Automation support" icon="setting">
    You want documentation images to stay in sync with the real thing, right?
    Regenerate them in CI, with replay support included.

    [Learn more →](/en/automation/document-image-sync/)
  </Card>
  <Card title="Convert to other formats" icon="seti:video">
    No problem if your platform does not support SVG.
    You can convert to PNG, GIF, WebM, MP4, and more with built-in support.

    [Learn more →](/en/basic-usage/capturing-images/convert-to-png/)
  </Card>
  <Card title="Interactive capture" icon="seti:powershell">
    A mode is available where you can press `F9`/`F10` to capture at any time.
    You do not need to launch a screenshot tool every time while writing documentation.

    [Learn more →](/en/basic-usage/interactive-capture/)
  </Card>
  <Card title="Live Server feature" icon="server">
    Convert terminal sessions to SVG in real time and show them live in a browser.
    Even YouTube streaming is possible.

    [Learn more →](/en/utilities/live-server/)
  </Card>
  <Card title="Rich custom-theme support" icon="desktop">
    A wide variety of custom themes are supported.  
    You can change the terminal appearance to match your preferences.

    [Learn more →](/en/appearance/themes/built-in-themes/)
  </Card>
  <Card title="Windows support" icon="seti:windows">
    This is not something you can use only on macOS.  
    It works on Linux and, of course, Windows too.

    [Learn more →](/en/getting-started/installation/)
  </Card>
  <Card title="Built-in crop feature" icon="pencil">
    Automatically trim overly long output and extract only the parts you need.

    [Learn more →](/en/basic-usage/capturing-images/crop/)
  </Card>
  <Card title="Share safely" icon="padlock">
    Common passwords and usernames are masked automatically.
    This keeps you safe even if `APP_SECRET_TOKEN` accidentally appears in the output.

    [Learn more →](/en/basic-usage/masking-secrets/auto-masking/)
  </Card>
</CardGrid>
