## もっとも単純な例

自分自身の説明文をキャプチャしてみます。

```bash
console2svg capture -- console2svg
```

![`console2svg capture -- console2svg`の出力](/assets/cmd.svg)

## フレーム付き

macOSのターミナル風、横幅を指定して、実行コマンド名も付けています。

```bash
console2svg capture -w 100 -c -d macos-pc -- fastfetch
```

![macOS風のフレーム付きキャプチャ](/assets/cmd-window.svg)

## 背景・透過指定

なかなかおしゃれにできます。

```bash
console2svg capture -w 100 -h 10 -c -d macos-pc \
    --background "image1.png" --opacity 0.95 \
    -- oh-my-logo "console2svg" mint --filled --letter-spacing 0
```

![背景と透過率を指定したconsole2svgのHero画像](/assets/cmd-hero.svg)

## アニメーション
### sl

```sh
console2svg capture -c -d -v -- sl
```

![slのアニメーションキャプチャ](/assets/cmd-sl.svg)

### cmatrix

GIFへ直接出力することもできます。

```sh
console2svg capture -d -o cmatrix.gif --timeout 5 -- cmatrix -ab
```

![cmatrixをGIFへ変換した例](/assets/cmd-matrix-video.gif)

詳しくは[出力フォーマットの変換](/ja/basic-usage/converting-output-formats/)を参照してください。

### nyancat

```sh
console2svg capture -w 160 -h 32 -c -d -v \
  --timeout 5 --sleep 0.5 -- nyancat -d 10
```

![nyancatのアニメーションキャプチャ](/assets/cmd-nyancat.svg)

## リプレイ再生

事前に用意したリプレイファイルを再生することで、CI環境上でも同じ入力を再現できます。

```sh
console2svg replay ./replay.json -w 80 -h 20 -v -c -d macos -- bash
```

![リプレイから生成したインタラクティブセッション](/assets/cmd-bash-vim.svg)

## インタラクティブキャプチャ

`F9`キーで録画を開始して、もう一度`F9`キーで録画を終了します。静止画は`F10`です。

```bash
console2svg interactive -d macos -o ./captures/output.svg
```

![インタラクティブキャプチャ](/assets/cmd-interactive.svg)

## テーマ

組み込みでも、カスタムテーマでも、好きなテーマを指定できます。

```bash
console2svg capture -c -d macos -t dracula -- fastfetch
console2svg capture -c -t cyberpunk-pc -- fastfetch
```

利用できるテーマは[テーマ](/ja/appearance/themes/)または`console2svg theme list`で確認してください。

## 機密情報マスキング

自動マスクは標準で有効です。さらに確実に隠したい値がある場合は`--mask`を追加できます。

```bash
console2svg capture -d macos-pc -t github-dark \
  --mask "$APP_SECRET_TOKEN" -- printenv
```

マスキングは生成画像に対して行われます。元の環境変数、リプレイ、cast、ログ自体から機密情報が消えるわけではない点には注意してください。
