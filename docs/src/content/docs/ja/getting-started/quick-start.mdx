console2svgの[インストール](/ja/getting-started/installation/)が完了したら、早速使ってみましょう。

## 静止画を撮影する
### 簡単な例

<Steps>

1. `console2svg capture -- (any-command)`で好きなコマンドを実行します。

   ```bash
   console2svg capture -- console2svg
   ```

2. これで完了です。標準では`output.svg`に生成されます。

3. 生成された`output.svg`をブラウザで開いてみましょう。以下のような出力になっているはずです。

   ![`console2svg capture -- console2svg`の出力](/assets/cmd.svg)

</Steps>

### オプションを指定する

`capture`はいくつもオプション引数を受け付けます。
例えば、`fastfetch`を以下のような条件で表示させてみます。

* `-o fastfetch.svg`: 出力先を`fastfetch.svg`に変更します。
* `-w 100`: 端末の横幅を100文字に固定します。
* `-c`: 出力の先頭部分に`$ fastfetch`のような実行コマンドの表示を追加します。
* `-d macos-pc`: macOSのウインドウのような見た目にし、周囲に余白を設けます。
   * `-d`のみ指定した場合、`macos`として取り扱われます。
* `-t github-dark`: GitHub Dark風のカラーパレットを適用します。
* `--background "#006090"`: 青色の背景にします。

```bash
console2svg capture -o fastfetch.svg -w 100 -c -d macos-pc -t github-dark \
  --background "#006090" -- fastfetch
```

詳しくは[コマンド出力をキャプチャする](/ja/basic-usage/capturing-command-output/)を参照してください。

## 動画を撮影する
### 簡単な例

<Steps>

1. SVGをアニメーションにする場合は`capture`へ`-v`を渡してコマンドを実行します。

   ```bash
   console2svg capture -c -d -v -- sl
   ```

   > [!NOTE]
   > <code>-v</code>を指定しないSVG出力では、最終フレームだけを描画した静止画になります。

2. 以上で完了です。生成された結果は以下のようになります。

   ![`console2svg capture -c -d -v -- sl`の出力](/assets/cmd-sl.svg)

</Steps>

### オプションを指定する

例えば、`nyancat`を以下のような条件で表示させてみます。

* `-w 160 -h 32`: 幅160文字、高さ32行にします。
* `-c`: 出力の先頭部分に`$ nyancat`のような実行コマンドの表示を追加します。
* `-d`: macOSのウインドウのような見た目にします。`-d macos`と同等です。
* `-v`: アニメーションSVGを有効にします。
* `--timeout 5`: 5秒経過後に自動で終了させます。
* `--sleep 0.5`: 最終フレームからリピートするまで0.5秒待機します。

```bash
console2svg capture -w 160 -h 32 -c -d -v \
  --timeout 5 --sleep 0.5 -- nyancat -d 10
```

![`nyancat`のアニメーションキャプチャ](/assets/cmd-nyancat.svg)

詳しくは[コマンド出力をキャプチャする](/ja/basic-usage/capturing-command-output/)を参照してください。
