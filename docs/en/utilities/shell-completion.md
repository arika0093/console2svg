---
title: Shell completion
description: Install tab-completion scripts for bash, zsh, fish, and PowerShell.
---

The `completions` subcommand outputs completion scripts for various shells.

> [!TIP]
> These completion scripts are generated by [System.CommandLine.StaticCompletions](https://github.com/dotnet/command-line-api/blob/main/src/System.CommandLine.StaticCompletions/README.md).

## Installing for each shell

### Bash

Add the following to `~/.bashrc`:

```bash
eval "$(console2svg completions script bash)"
```

### Zsh

Add the following before the `compinit` call in `~/.zshrc`:

```zsh
eval "$(console2svg completions script zsh)"
```

### Fish

Place the script in the completions directory:

```fish
mkdir -p ~/.config/fish/completions
console2svg completions script fish > ~/.config/fish/completions/console2svg.fish
```

### PowerShell

Add the following to the PowerShell profile (`$PROFILE`):

```powershell
Invoke-Expression (& console2svg completions script pwsh | Out-String)
```
