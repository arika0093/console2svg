---
title: アニメーション SVG の生成
description: 保持した端末状態を行定義へ集約し、SMIL の離散表示として出力する仕組み。
---

アニメーション SVG はスクリーンショット列から作るのではなく、端末状態の時系列から作ります。
`AnimatedSvgRenderer` は静止画と同じ端末エミュレーターへ録画を順番に流し、必要な状態だけを保持した後、再利用可能な行定義へ変換します。

## 端末状態をフレームとして保持する条件

PTY や asciicast のイベント境界を、そのままアニメーションのフレーム境界とは見なしません。
一回の TUI 更新が複数の write に分かれることがあり、可視セルを変えずにパーサー状態だけを変えるイベントもあるためです。

実運用の replay 経路では、各イベント後に `ScreenBuffer.GetContentSignature()` を比較します。
このシグネチャにはカーソルを含めないため、カーソル移動だけでは本文の **保持フレーム** を増やしません。

`--fps` が正の場合は最小フレーム間隔も適用します。
その区間に複数の可視変更があれば、最後の変更状態を保留して採用します。
途中まで描かれた状態をすべて保存するのではなく、同じ時間窓の最後の状態を残す方式です。

スナップショットは行単位のコピーオンライトを使います。
作成時には変更していない行を live buffer と共有し、その後に書き換える行だけを複製します。
FPS 窓内の保留フレームを更新する場合も、画面全体の deep copy は行わず、行参照とシグネチャ情報を最新状態へ差し替えます。

先頭状態と末尾状態は保持します。
時刻の正規化によって複数フレームが同じ時刻へ重なった場合は、SMIL の key time が逆行または重複しないように時刻をわずかに広げます。

## フレーム全体ではなく行をカタログ化する

保持フレームが決まった後は、画面全体をフレーム数だけ SVG 化しません。

`PrepareAnimatedRows` は各可視行のビジュアルシグネチャを読み、**行カタログ** を作ります。
同じシグネチャを持つ行が見つかっても、実際のセルを比較してから既存定義を再利用します。
シグネチャは候補検索の高速化に使い、表示内容の正しさを hash 一つへ委ねません。

新しい一意行が見つかった時点で、その行に必要な文字スタイルも収集します。
同一行が多数のフレームに存在しても、同じ行をスタイル収集のためだけに再走査しません。

各フレームには、物理行ごとの行定義 index を持つ配列を対応させます。
SVG の `<defs>` には一意な行だけを書き、表示時には `<use>` で参照できます。

## 小さな変更を行差分として表す

文字入力や status 表示では、一行の数文字だけが変わることがあります。
この場合は **行差分** を使い、直前の行定義を参照して変更列だけを上書きできます。

差分は常に使うわけではありません。
変更幅は16列以下、かつ可視行の4分の1以下に制限します。
参照の深さも4段未満に抑えます。

変更範囲が全角文字の継続セルに触れる場合は、文字の途中で分割しないよう開始位置または終了位置を広げます。

手動マスクパターンがある場合は行差分を無効にします。
秘密文字列が変更していない部分と差分部分をまたぐと、分割後の片方だけでは完全な一致を検出できないためです。

## 行描画の一時領域を再利用する

行定義を SVG へ出す際には、罫線線分、角丸、ブロック矩形、path data、前景文字列、マスク検出用の正規化文字列が必要です。
`FrameRenderWorkspace` はこれらの List と `StringBuilder` を保持し、定義ごとに内容だけを消して再利用します。

可視行は `GetVisibleRow` から span として取得し、列 loop の中ではその span を直接参照します。
scrollback を使わない通常経路で、セルごとに汎用アクセサーを呼ぶ回数を減らします。

## 行の表示区間を SMIL で切り替える

各物理行について、同じ行定義を参照し続ける連続フレームを一つの run にまとめます。
run ごとに一つの `<use>` を置き、**SMIL** の `display` animation で表示時間を指定します。

`calcMode="discrete"` を使うため、中間値の補間は行いません。
端末行は境界時刻の前後で別の状態へ切り替わります。

例は次の形です。

```xml title="output.svg"
<animate
  attributeName="display"
  values="none;inline;none"
  keyTimes="0;0.25;0.5"
  calcMode="discrete"
  dur="4s"
/>
```

ループする場合は `repeatCount="indefinite"` を付けます。
ループしない場合は最終状態を freeze します。
fade-out は各行へ個別に付けず、最後の保持時間の後で親 group の opacity を下げます。

文字の blink は画面状態の切替とは別で、CSS animation として扱います。

## カーソルを本文から分離する

カーソルの表示状態と位置は、行本文とは別の run にまとめます。
カーソルだけが移動しても、同じ行定義を作り直す必要はありません。

本文フレームの削減でカーソルを除いたシグネチャを使えるのは、この分離があるためです。
カーソルの時刻変化はアニメーション層で保持し、本文の行重複排除とは独立して処理します。

## 時間範囲と末尾状態を調整する

開始時刻を指定した場合は、その時刻より前に存在する最後の状態を必要に応じて先頭へ補います。
選択した区間は0秒起点へ移します。

`--sleep` が指定されていれば、最終状態をその時間だけ保持します。
指定がない場合も、末尾が現れた瞬間に消えないよう最小の保持時間を設けます。
`--fade-out` はその保持後に開始します。

全画面アプリは終了時に代替画面を抜け、空の主画面へ戻すことがあります。
末尾がその復元だけで空画面になる場合は、その復元部分を除き、直前の有効な表示を最終状態として残せます。
