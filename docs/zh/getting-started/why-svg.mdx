console2svg 会将终端输出保存为 SVG。
SVG 不只是用于显示图片，它也非常适合清晰、易用地共享像终端这样的文字为主的画面。

## 任意尺寸都清晰

请先对比以下两张图片。

```bash title="Terminal"
$ fastfetch
```

### SVG
{/* c2s:: -o why-svg-fastfetch.svg -w 120 -h 24 -- fastfetch */}
<img width="800" src="/assets/why-svg-fastfetch.svg" />

### PNG
{/* c2s:: -o why-svg-fastfetch.png -w 120 -h 24 -- fastfetch */}
<img width="800" src="/assets/why-svg-fastfetch.png" />


可以看到，前者的文字更清晰。
由于 SVG 是矢量格式，即使放大或缩小，文字和框线也不会模糊。无论在 README、博客文章、幻灯片、印刷品等不同位置或尺寸显示，都能保持相同质量。

## 文件体积小

比较上面两个文件的大小可以看到，SVG 版明显更小（约为 1/5）。

<FileTree>

* output.png (60,717 bytes)
* output.svg (8,455 bytes)

</FileTree>

## 可以直接在浏览器中显示

SVG 是主流浏览器默认支持的开放 Web 标准。
无需准备专用查看器或转换工具，就可以在浏览器中打开生成的文件，或嵌入到 Markdown、HTML 中。

```markdown title="README.md"
![your terminal output](./output.svg)
```
