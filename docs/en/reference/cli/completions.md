---
title: completions
description: Command that generates shell completion scripts.
---

```bash title="Terminal"
console2svg completions generate <shell>
```

Specify a shell name such as `bash` or `zsh` to generate a completion script.

## Subcommands and arguments

### `generate <shell>`

Generate a completion script for the specified shell. Supported shell names include `bash`, `zsh`, `fish`, and `pwsh`.
