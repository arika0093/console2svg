You can directly convert captured SVG animations to common video formats such as GIF and MP4 when outputting them.

## Output examples

Specify the desired extension with the `-o` option (or use `--format`). If `ffmpeg` is installed on the system, encoding runs automatically.

### GIF animation

```bash title="Terminal" "-o demo.gif"
console2svg capture -v -o demo.gif -- cmatrix -ab
```

## How it works

Animated SVGs cannot be converted directly to various video formats as-is. Therefore, conversion roughly follows the steps below.

<Steps>

1. Extract the generated animation as one SVG per frame with [save-frames](./save-frames).

2. If direct conversion from `svg` is possible (when `librsvg` is enabled), simply concatenate all SVGs and pass them to `ffmpeg`.

3. If direct conversion from `svg` is not possible, first convert them to [PNG images](../capturing-images/convert-to-png.md) with `resvg`, then pass them to `ffmpeg`.

</Steps>

This makes conversion to video formats possible in many different environments.
