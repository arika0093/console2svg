description: 分离外观设置和终端正文，并在动画中复用静态部分的 SVG 层级。

输出 SVG 不会把“终端内容”和“放置它的相框”混在一起。即使只更新画面内容，也不需要重新绘制背景图片、macOS 风格或 Windows 风格窗口装饰、留白和命令标题。特别是在动画中，静态外框只输出一次，内部只切换终端的行。

## 从画布到终端的顺序

首先放置 SVG 的 `width`、`height`、`viewBox`、通用字体 CSS 和样式定义。然后绘制画布背景。

带桌面的 chrome 会把默认渐变或指定背景放到整个画面，普通 chrome 则只放置明确指定的背景。本地图片可以嵌入为 data URI，因此即使作为单个文件发布，也不依赖指向背景的相对路径。

其上放置窗口阴影、边框和标题栏，再用主题背景填充终端客户端区域。这是为了避免 padding 部分透明，并让 chrome 内侧看起来像一整块终端。

`--with-command` 的标题也包含在这个静态区域中。最后放置终端帧，并按单元格背景、文字、图形片段、光标、遮罩覆盖层的顺序叠加。先放背景可以确保反色单元格或半透明光标始终拥有正确底色。

## 在一个地方决定坐标

`SvgDocumentBuilder.Context` 会解析裁剪、滚动历史、margin、padding、chrome、标题和 `--size`，然后保存正文起始坐标和显示范围。单元格宽度是字体大小的 0.6 倍，单元格高度是 `18 / 14` 倍，基线以字体大小为基准。由于所有终端元素都引用同一上下文，背景矩形、文字、框线、光标的坐标计算不会分别偏移。

即使指定输出尺寸，也不会直接拉伸正文几何。如果只指定一边，则保持比例决定 SVG 尺寸；如果两边都指定，则选择可容纳的缩放倍率，多余部分作为 `viewBox` 侧的背景区域。这种分离能在保持包含 chrome 的自然布局的同时，适配嵌入目标所需的外形尺寸。

## 动画中的边界

在动画 SVG 中，外侧背景、chrome 和标题只关闭一次，正文行定义输出到 `<defs>`。之后打开内容偏移用的组，并放置各行的 `<use>` 和 SMIL。由于图层顺序与静态图片共享，转换为视频前后配色和裁剪含义都不会改变。
