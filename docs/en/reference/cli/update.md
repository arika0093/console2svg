---
title: update
description: Command that checks for and runs console2svg updates.
---

```bash title="Terminal"
console2svg update [--check] [--force] [--yes]
```

`--check` only checks, `--force` updates even when the installation is managed by a package manager, and `--yes` skips confirmation prompts.

## Options

### `--check`

Only check for available updates; do not install.

### `-f, --force`

Update even installations managed by a package manager.

### `-y, --yes`

Skip confirmation prompts.
