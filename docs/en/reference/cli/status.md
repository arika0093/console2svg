---
title: status
description: Command that checks the execution environment and dependency tool status.
---

```bash title="Terminal" "--format table|markdown|json" "--json"
console2svg status [--format table|markdown|json]
console2svg status --json
```

Displays detected status for the version, OS, runtime, SVG renderer, themes, ANSI colors, and more.

## Options

### `--format <table|markdown|json>`

Choose the output format from `table`, `markdown`, or `json`.

### `--json`

Output status in JSON format. This is the same as `--format json`.
