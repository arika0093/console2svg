---
title: update
description: console2svg の最新リリースを確認し、バイナリを自動更新するコマンド。
---

```bash title="Terminal"
console2svg update [options]
```

`update` は、GitHub 上の最新リリースを確認し、実行中の console2svg を最新バージョンへ自動的に更新（セルフアップデート）するためのサブコマンドです。
手動でアーカイブをダウンロードして配置し直す手間をかけずに、最新の機能や修正を取り込めます。

## コマンドの動作

コマンドを実行すると、GitHub Releases API を問い合わせて最新バージョンを確認します。
新しいバージョンが存在する場合は、現在の OS および CPU アーキテクチャに合致するリリースアーカイブを自動取得し、実行ファイルを置き換えます。

なお、Homebrew や Scoop などのパッケージマネージャー経由でインストールされている場合は、パッケージマネージャーの管理整合性を保つため、標準ではセルフアップデートを抑止してパッケージマネージャー側での更新を促します。

## オプション

### `--check`

利用可能な最新バージョンの有無を確認するだけで、実際のダウンロードや更新は行いません。現在のバージョンと最新バージョンを比較したい場合に利用します。

```bash title="Terminal"
console2svg update --check
```

### `-y, --yes`

アップデート実行前の確認プロンプト（`Do you want to update? [y/N]`）をスキップし、自動的に更新処理を進めます。CI スクリプトや無人実行に適しています。

### `-f, --force`

パッケージマネージャー（Homebrew や Scoop 等）によってインストールされている環境であっても、警告を無視して直接バイナリを上書き更新します。
