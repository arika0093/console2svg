console2svg turns terminal output into images for READMEs, blog posts, issue reports, and build artifacts. SVG is the primary format, so text stays crisp when a reader zooms in. Static captures are the default; animations, video conversion, and live browser previews are available when a screenshot is not enough.

![A console2svg hero image generated by console2svg](/assets/cmd-hero.svg)

## Why console2svg?

<CardGrid>
  <Card title="Sharp terminal images" icon="image">Render ANSI and Truecolor output as SVG instead of a blurry raster screenshot.</Card>
  <Card title="More than one capture mode" icon="rocket">Capture commands and pipes, work in an interactive shell, replay input, or capture a tmux pane.</Card>
  <Card title="Made for automation" icon="setting">Use explicit sizes, timeouts, replay files, masking, and GitHub Actions for repeatable captures.</Card>
</CardGrid>
