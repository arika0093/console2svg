console2svgをお好きな手段でインストールしましょう。

## 対応プラットフォーム

まあ、大体のプラットフォームではきっと動くはずです。

<Tabs>
  <TabItem label="Windows">
    * x64 / arm64
    * Windows 10以上のみサポート(`ConPTY`が必須)
  </TabItem>
  <TabItem label="Linux">
    * x64 / arm64
    * Ubuntu 24環境でテストしていますが、多くのディストリビューションで動作します。
  </TabItem>
  <TabItem label="macOS">
    * x64 / arm64
  </TabItem>
</Tabs>

## 内蔵アップデート機能

GitHub Releaseまたはインストールスクリプトで導入した場合、自己更新型のアップデートを利用できます。

```bash
console2svg update
```
