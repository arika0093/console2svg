title: 序列解释
description: 带状态读取被分割的 VT 输出，并反映到单元格画面、滚动和属性中的终端模拟。
---

终端输出不是带装饰的文本，而是操作画面的指令序列。例如，进度显示会在不增加换行的情况下把光标移回，TUI 会只清除并重绘特定区域。转换侧不是处理去掉 ANSI 后的字符串，而是作为小型虚拟终端执行指令，这是为了复原最终的单元格布局。

## 块边界不是指令边界

来自 OS 的读取单位可能在 `ESC [`、参数或终止字节中途断开。`AnsiParser` 会保存未完成的 ESC 序列，以及被 ECHOCTL 显示为 `^[` 的未完成 OSC 序列，并连接到下一次 `Process` 调用的开头。没有这种状态保持时，被分割控制指令的后半部分就会被当作普通字符绘制。

CSI 会分离 private marker、参数和 final byte；参数少的普通情况使用栈区域，只有参数多时才使用共享池数组。这样即使大量输出也不会增加 GC，并能让解析器位于录制热路径。未指定的值会解析为各指令的默认值，未知的 private CSI 不会被误解为样式指令，而是忽略。

## 画面操作和文字属性

已实现的 CSI 包括光标移动和绝对位置、显示/行擦除、字符插入/删除、行插入/删除、滚动、滚动区域、制表位、insert mode、保存/恢复。DEC private mode 处理备用画面、origin mode、光标显示。全屏应用会使用备用画面，因此需要在不覆盖主画面的情况下切换到单独缓冲区，并在结束时恢复原画面。

SGR 会在 `TextStyle` 中保存粗体、淡色、斜体、下划线、闪烁、反色、隐藏、删除线、上划线，以及 16 色、256 色、RGB、下划线颜色。256 色会解析为主题前 16 色、6×6×6 色块和灰阶，truecolor 则原样作为 RGB 字符串。除了 `;` 分隔，也能读取 `:` 分隔的颜色参数，因此不同终端的 SGR 表记差异会反映为相同颜色属性。

可打印字符会考虑单元格宽度进行放置。代理对、variation selector、组合字符会合并到前一个单元格，零宽字符不会推进列。DEC special graphics 的 G0/G1 字符集也会翻译为框线字符。解析器不是“把字节序列变成字符串”的层，而是把含义恢复到后续可以生成带坐标 SVG 的层。
