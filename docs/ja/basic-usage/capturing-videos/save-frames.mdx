アニメーションの各フレームを独立した画像ファイルとして取り出したい場合、`--save-frames` オプションを使用します。

## 連番画像の保存

`--save-frames` に保存先ディレクトリを指定して実行します。

```bash title="Terminal" "--save-frames ./frames"
console2svg capture -v --save-frames ./frames -- sl
```

指定したディレクトリ配下に、各フレームが `frame-0000.svg`, `frame-0001.svg` のような連番ファイル名で出力されます。

  - frame-0000.svg
  - frame-0001.svg
  - frame-0002.svg
  - frame-0003.svg  以下略

</FileTree>

## サンプリングレートの指定

`--fps` オプションと組み合わせることで、サンプリング間隔を調整できます。

```bash title="Terminal" "--fps 10" "--save-frames ./output-frames"
# 1秒あたり10フレームのレートで出力
console2svg capture -v --fps 10 --save-frames ./output-frames -- nyancat
```
