`console2svg status` は、現在の実行環境、各種レンダラーの動作状況、および利用可能な機能を一覧表示して診断するためのコマンドです。
動画変換や各種画像フォーマットへの出力、tmux 連携など、外部ツールに依存する機能が正しく動作するかどうかを事前に確認できます。

## 実動作によるツールの検証

一般的なコマンドが `PATH` 上のファイル有無だけを見て利用可否を判定するのに対し、`status` コマンドは各外部ツールを実際にサブプロセスとして起動してバージョン番号や応答を取得します。
実行権限の不足や壊れたシンボリックリンクによって「パスは通っているのに実際には動かない」という環境トラブルを早期に検出するためです。

特に SVG レンダラーに対しては、最小限の SVG を実際にラスタライズできるかどうかの試験実行（プローブ）を行い、確実に利用可能なコンバーターだけを `available` として報告します。

## コマンドの実行

引数を指定せずに実行すると、現在のコンソールに合わせて色付けされた表形式で結果が表示されます。

```bash title="Terminal"
console2svg status
```

出力例（お使いの OS やインストールされているツールによって内容や利用可否は変化します）：

<!-- c2s::  -w 100 -- console2svg status -->

表示される項目は次のカテゴリに分かれています。

* **Application**: console2svg のバージョン、インストール元チャネル、Native AOT の適用状況
* **Platform**: 実行中の OS、CPU アーキテクチャ、ランタイム（.NET）のバージョン
* **Renderers**: 同梱 resvg、rsvg-convert、ffmpeg の検出状態および動画用 MP4 コーデック（libx264 など）
* **Features**: 動画キャプチャや tmux 連携など、各機能が実行可能かどうかの判定
* **Themes**: 組み込みテーマおよびカスタムテーマの認識件数
* **Colors / Formats**: ターミナルの ANSI カラー対応状況と、出力可能な拡張子一覧

## 出力フォーマットの切り替え

`--format` オプションを指定することで、用途に応じた出力形式を選択できます。

```bash title="Terminal" "--format markdown"
console2svg status --format markdown
```

* `--format table`（既定値）：端末上で人間が読むための見やすいカラー表形式です。
* `--format markdown`：GitHub の Issue や Pull Request、ディスカッションにそのまま貼り付け可能な Markdown 表形式です。不具合報告時の環境情報共有に適しています。
* `--format json`（または `--json`）：スクリプト処理や CI パイプラインでの自動診断に適した、詳細な JSON 形式です。
